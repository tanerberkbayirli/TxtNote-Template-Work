## Known deviations / conflicts (recorded, not hidden)

- **Table continuation caption: '(Devam)' is bold with the label**: The guide example (p.30) prints 'Tablo 1.' bold and '(Devam)' regular; the engine styles all text before {title} as the label. The text rule only prescribes the words. Not asserted.
- **Appendix list (EKLER DİZİNİ)**: Not generated by the engine: optional editable section typed by the author, formatted like the lists (limitation).
- **Inner cover blank-line structure**: EK 2a (4/3/4/3, INFERRED) vs official Word forms (3-member 2/3/3/3, 5-member 2/3/2/2, TEMPLATE) vs guide text (silent): the Word forms' counts are implemented; with the guide's 12/16 pt at 1.5 lines the EK 2a counts overflow one sheet for a 4-line title (see source.notes).
- **Official inner-cover DOCX forms (14 pt, 25 mm margins) vs guide text (16 pt title, 12 pt names, 25/25/30/30)**: CONFLICT recorded; the guide's explicit text wins. The spec did not analyse the DOCX forms (Ic_Kapak_*_2026.docx, Etik_Beyan_Formu_2022.docx, Enstitu_Onayi_Formu_2024.docx).
- **katex dev dependency returns 504 (Outdated Optimize Dep) on the running dev server**: Environment noise: equations are not part of this target; the fixtures contain no equation so the export is clean.
