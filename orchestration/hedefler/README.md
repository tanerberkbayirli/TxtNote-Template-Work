# Hedef kayıtları

`<kimlik>.CONTEXT.md` dosyaları hedefin kimliğini, kaynak kararlarını ve tarihli bağlamını tutar. Bunlar çalışma talimatı veya güncel PASS belgesi değildir. Eski “current/latest” ve “not yet” ifadeleri kendi kayıt tarihleriyle değerlendirilir; kaynak önceliği [BASLA.md](../BASLA.md) içindedir.

Önce [rapor dizinindeki](../raporlar/README.md) daha yeni kapsamı kontrol edin. Kaynak künyeleri [sablon-kaynaklari/](../sablon-kaynaklari/README.md), makinenin kullandığı spec/check/fixture verileri `engine/specs/`, ham türetilmiş kaynak verileri `engine/references/` altındadır.

Eski `references/` metin dökümleri aktif talimat ağacından çıkarıldı; temizlik öncesi tam içerikleri `.test-tmp/validation/orchestration-sadelestirme-20261026/orchestration-before.zip` içinde korunur. Başlık/metadata ürün kararları [TEZ_BILGILERI.md](../uygulama/TEZ_BILGILERI.md) içinde birleştirildi.
